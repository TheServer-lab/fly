# Fly

**The programming language for people who want Python's simplicity without Python's ecosystem sprawl.**

Fly is a high-level, dynamically typed, general-purpose programming language that compiles to native executables.

Write readable code. Compile it to a native exe. Manage dependencies. Build. Run. Test. Format.

> **Status: 0.1.3** - This document describes Fly **as implemented** in the current repository. Where implementation, tests, and this document disagree, implementation and passing tests are authoritative. Anything marked *planned* is not yet shipped.

```text
.fly → Lexer → Parser → Sema → LLVM IR → LLVM Opt → Native Backend → Linker → exe
```

No VM. No interpreter for normal execution. Native compilation via LLVM, runtime via `libflyrt` with ARC.

Fly ships three executables: `fly` (toolchain), `fly-cc` (compiler), `fly-repl` (REPL).

---

## Why Fly?

You usually get two bad choices:

1.  Friendly language, but you juggle compiler + package manager + build system + formatter + test runner + venv
2.  Powerful systems language, but you fight the language more than you build software

Fly is a different idea:

> **The language and the toolchain should feel like one product.**

```text
fly
├── -new / -init
├── -compile
├── -build
├── -run
├── -test
├── -deps
├── -dump
├── -format
├── -clean
└── -up
```

You install Fly and you have everything.

## Quick Start

```cmd
fly -new myapp
cd myapp
fly -run
```

What `-new` made:

```text
myapp/
├── flylink.sleep   <- SLEEP manifest. Auto-generated. You don't need to edit it.
├── src/
│   └── main.fly
├── module/         <- where Dump packages live
└── bin/
```

### What is `flylink.sleep`?

Yes, like `.zip` and `.com` - it's a file extension that looks like a word.

SLEEP = **Simple Lightweight Extensible Expression Protocol**

It's the project manifest. It is auto-generated by `fly -new`. `fly -deps` and `fly -dump install` update it. You generally don't hand-edit it.

```sleep
project
  name "myapp"
  version "0.1.0"
  source "src/main.fly"
  output "bin/myapp"
  deps coll ["http"]
  icon "assets/myapp.ico"
```

Fields: `project, name, version, source, output, deps, icon, test`. Unknown keys ignored.

## A Fly Program

```fly
name = take("What is your name? ")

if name == "Rick" {
    show("Welcome back, {name}!")
}
orif name == "admin" {
    show("Administrator access granted.")
}
ifnot {
    show("Hello, {name}!")
}
```

Functions are `job`:

```fly
job add(a, b) {
    give a + b
}

result = add(10, 20)
show("Result: {result}")
```

Dynamic typing:

```fly
value = 42
value = "Hello"
value = Yes
```

## Toolchain CLI

### `fly` - The System

```text
fly                              launch REPL
fly -new <name>                  scaffold new project ( -init is alias )
fly -compile <file>              compile single .fly file
fly -format <file>               format file
fly -deps [--offline]            install deps from flylink.sleep into module/
fly -build                       build project from flylink.sleep
fly -run [args...]               build if needed, then run project
fly -test                        build and run tests
fly -clean                       remove build artifacts (never source/deps)
fly -dump install "pkg"          install package
fly -dump remove "pkg"           remove package
fly -dump list                   list installed
fly -dump update                 re-fetch installed
fly -up                          update toolchain to latest release
fly -help | -h | --help
fly -version | --version
```

### Compile Modifiers - For Single File & LLMs

```text
fly -compile file.fly                 compile and KEEP binary
fly -compile file.fly -o name         custom output name ( .exe normalized on Windows )
fly -compile file.fly -icon app.ico   embed Windows PE icon (default: toolchain fly.ico)

fly -compile file.fly -run            compile → run once → KEEP binary
fly -compile file.fly -done           compile → run once → clean .o/.rc, KEEP binary
fly -compile file.fly -finish         compile → never run → clean transient, KEEP binary (release-ready)

For projects:
fly -build -finish                    release build
fly -run -done                        run and clean transient artifacts
```

**Why `-run` / `-done` / `-finish`?**
This is for test loops and LLMs. If you do:

```cmd
fly -compile debug_server_3.fly -run
```

It compiles to a temp binary, runs it, shows stdout ONCE, then cleans the temp. No `debug_server.exe, debug_server_1.exe, debug_server_2.exe` garbage. Workspace stays clean. Perfect for:

```fly
$ your kounter test
fly -compile kounter-test.fly -run
--- kounter basic ---
PASS  abs(-5)  got=5
...
--- done ---
```

### `fly-cc` and `fly-repl`

`fly-cc` is the native compiler (lexer, parser, sema, IR, LLVM). `fly` dispatches to the copy next to itself.

`fly-repl` is the interactive REPL - each turn compiled via real `fly-cc`, no separate interpreter.

```text
>>> 1 + 1
2
>>> a = 10
>>> show("hi {a}")
hi 10
```

## Language Specification (0.1.3)

### Comments

```fly
$ single line

$$
multi line
$$
```
`#` and `//` are NOT comments.

### Core Types

| Type | Meaning |
|------|---------|
| `tex` | text (UTF-8 string) - short for text |
| `num` | 64-bit signed integer |
| `dec` | double |
| `yn` | boolean Yes/No |
| `coll` | ordered collection (array) - short for collection |
| `board` | key/value map - imagine classroom blackboard with notes |
| `emp` | empty value EMP |
| `job` | callable function value |

```fly
age = num("18")      $ cast, throws catchable error on failure
price = dec("19.99")
text = tex(123)
```

Booleans are exact case: `Yes` `No`. `yes`, `YES` are identifiers.

### Variables

```fly
a = 10
a = "hello" $ mutable by default

hard pi = 3.14 $ immutable, reassign = compile error
```

### Operators

```text
+ - * / %
== != < > <= >=
and or not
```
All lower to libflyrt calls. Unary minus is `fly_rt_neg`.

### Collections

```fly
items = [10, "hello", Yes, 3.14] $ mixed types
items[0] $ zero-based
items[1:4] $ slice inclusive start, exclusive end
items[:3] items[2:] items[:]
```

### Boards

```fly
person = {
    "name": "Rick"
    "age": 18
}

$ commas optional, newline-separated works too
```
Lookup is O(n) linear scan by value equality.

### Functions

```fly
job add(a, b) {
    give a + b
}

job greet(name) {
    if name == EMP {
        give "Nobody"
    }
    give name
}

$ bare give returns EMP
job noop() {
    give
}

$ native job = implemented in libflyrt C
native job sha256(text)
```

### Input / Output

```fly
name = take("Name: ") $ prints prompt, reads line -> tex
show(name)
show(10 + 5)
```

### Text & Interpolation

```fly
show("Hello {name}")
show("Result: {add(10, 5)}") $ expressions evaluated when text created
show("Use {{name}} literally.") $ prints {name}
```

### Conditions

```fly
if condition {
}
orif other {
}
ifnot {
}
```

### Loops

```fly
while condition {
}

for item in items {
    show(item)
    skip   $ continue
    getout $ break
}
```
`skip`/`getout` outside loop = compile error.

### Error Handling

```fly
do {
    value = num("hello")
}
grab (err) {
    show("Conversion failed.")
}
```
Errors are real runtime values thrown via C++ exception ABI, caught by `grab`. Unhandled = terminate with message + non-zero exit. No `finally`.

### Type Casting

```fly
num("42") $ strict, num("42abc") throws
dec("3.14")
tex(123)
```
Failures are catchable with `do`/`grab`.

### Modules

```fly
bring path
bring filesystem
bring http
bring hashbox as hb $ alias

response = http.get_tls("https://example.com")
```

Resolution order (ModuleMerger::resolveModule):
1. Next to bringing file `<fromDir>/<name>.fly`
2. `<fromDir>/src/<name>.fly`
3. Bundled stdlib dir (FLY_BUILTIN_STDLIB_DIR)
4. `FLY_STDLIB_DIR` env override
5. `<projectRoot>/module/<name>.fly` (project root = walk up ≤8 levels for flylink.sleep)
6. `<fromDir>/module/<name>.fly` fallback

Stdlib wins over installed packages.

### Collection / Text Operations

```fly
attach(items, value)        $ append coll
place(items, index, value)  $ insert, also board set place(board, key, value)
erase(items, index)         $ remove
count(items)                $ length coll/board/tex, also items.length()
seek(items, value)          $ index or EMP
has(items, value)           $ Yes/No
bind(items, ", ")           $ join coll -> tex
sever("A,B,C", ",")         $ split tex -> coll
cut(text)                   $ trim whitespace
raise(text)                 $ uppercase
lower(text)                 $ lowercase
```

All byte/code-unit oriented, not Unicode codepoint.

### Reserved Keywords

```text
if orif ifnot while for in job give take show bring do grab hard native skip getout
attach place erase count seek has bind sever cut raise lower and or not Yes No EMP
```

## Built-in API (61 compiler-known callables)

These are `stdlib/*.fly` stubs lowered directly in `codegen.cpp`.

**Standalone:**
```text
show(value)  take(prompt)  num() dec() tex()
```

**path.* (7):** `basename, dirname, extension, stem, absolute, separator, join(a,b,...) variadic`

**filesystem.* (11):** `exists, isfile, isdir, read, write, append, mkdir, remove, list, cwd, chdir`

**process.* (5):** `args, run(cmd,args)->exitcode, spawn->pid, wait(pid), exit(code)`

**environment.* (3):** `get(name)->tex or EMP, exists, set(name,value)`

**system.* (3):** `os()->"windows"/"linux"/"macos", arch, hostname`

**net.* (8):** `resolve(host)->IP, connect(host,port)->fd, connect_tls->TLS handle (throws), listen, accept, send, receive(fd,max)->tex, close`

**gui.* (6):** `window(title,w,h)->handle, label(text), button(text), textbox, run()->EMP when last window closes, close(handle)` + sugar `widget.add(child), widget.on_click(job)`

Win32 automatic, GTK4 detected on Linux (optional), otherwise throws catchable error.

## Public Modules - Dump (The Dumping Ground)

Dump is not a scary word. `fly-dump` is a GitHub repo `TheServer-lab/fly-dump` / `public/` where all public Fly modules live. Installing is like installing a game from Play Store.

| Package | Provides |
|---------|----------|
| `sleep` | SLEEP v1.0 library for manifest/data format |
| `http` | HTTP/1.1 client built on `bring net` (TLS via net.connect_tls) |
| `hashbox` | `hashbox.sha256(text), hashbox.file_sha256(path)` SHA-256 via OpenSSL |

Upstream: `https://raw.githubusercontent.com/TheServer-lab/fly-dump/refs/heads/main/public/<name>.fly`
Override: `FLY_DUMP_URL_BASE`
Offline fallback: `dump-mirror/*.fly` in repo
Windows TLS: respects `SSL_CERT_FILE` with `--cacert --ssl-no-revoke`

## Runtime `libflyrt`

Static C lib `runtime/*.c` + `eh.cpp`. Found next to exe at runtime.

**FlyValue:**
```c
typedef struct { int64_t tag; int64_t payload; } FlyValue; // 16 bytes
```
Tag: 0 NUM, 1 DEC, 2 YN, 3 EMP, 4 TEX, 5 COLL, 6 BOARD, 7 JOB (function ptr)
Payload: int value / double bits / pointer.

**ARC:** Every heap object starts `FlyObjHeader { uint32_t refcount }`. Temporaries +1 owned, owner transfers into binding/container or releases once. Non-atomic in 0.1.3. Cycles = known limitation.

**92+ ABI symbols:** `fly_rt_show, fly_rt_add/sub/mul/div/mod/eq/..., fly_rt_text_from_cstr, fly_rt_strbuild_*, fly_rt_coll_new/push, fly_rt_board_new/put/get, fly_rt_iter_new/has_next/next, fly_rt_throw_value, fly_rt_net_*, fly_rt_gui_*, fly_sha256` etc. See `runtime/flyrt.h`.

## Compiler Architecture

```text
.fly
 ↓ Lexer (src/lexer)
 ↓ Parser (re-lexes interpolation via sub-lexer)
 ↓ AST (src/ast)
 ↓ Sema (hard reassignment, skip/getout, arity)
 ↓ IRGen (src/codegen, builtins dispatch, module aliases)
 ↓ LLVM modules → linking → optimization → backend (x86, AArch64)
 ↓ Linker (cc + libflyrt.a + icon resource + -lgdi32 -luser32 on Windows)
 ↓ Native exe
```

## Updates

`fly -up` reads `latest.txt` from `FLY_UP_LATEST_URL` (default GitHub releases latest/download), compares vs `FLY_VERSION`, downloads platform artifact. Windows spawns self-replacing child, POSIX forks detached helper.
